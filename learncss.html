Beginner · Foundations

Select an element and style it

A CSS rule has a selector (what to match) and declarations (what to change). A class selector starts with a dot and can be reused on many elements.

.welcome-card {
  color: #164b39;
  background-color: #e6f4e9;
}

Beginner · Layout basics

Understand the box model

Every element is a box: content sits inside padding, then the border, then the outside margin. box-sizing: border-box makes declared widths include padding and border.

* { box-sizing: border-box; }
.card { padding: 16px; border: 2px solid; margin: 12px; }

Intermediate · The cascade

Learn selectors and specificity

Selectors target elements in different ways. A type selector like p matches tags; .notice matches a class; #summary matches an ID. When rules conflict, the cascade considers origin, importance, specificity, and source order.

p { color: #53645b; }          /* type */
.notice { color: #1d6249; }    /* class wins over type */
#summary { color: #164b39; }   /* ID is more specific */

Try it: compare which selector wins

Good practice: prefer simple classes for reusable styling. IDs are best kept for unique page targets and JavaScript hooks.

Intermediate · One-dimensional layout

Arrange items with Flexbox

Flexbox lays items out along one axis. Use justify-content for the main axis, align-items for the cross axis, and gap for consistent spacing.

.toolbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 1rem;
}

Intermediate · Two-dimensional layout

Build layouts with CSS Grid

Grid controls rows and columns together. Define tracks with grid-template-columns; fractional units (fr) distribute available space. minmax() and auto-fit help make flexible grids.

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(140px, 1fr));
  gap: 1rem;
}

Advanced · Responsive design

Adapt to the available space

Media queries apply rules when the viewport matches a condition. Start with a layout that works in a narrow space, then add breakpoints when the content needs them—not for a particular device model.

.cards { display: grid; grid-template-columns: 1fr; }
@media (min-width: 42rem) {
  .cards { grid-template-columns: repeat(2, 1fr); }
}

7

Advanced · Motion and interaction

Add thoughtful transitions and animation

Use transitions for changes between states and keyframes for multi-step motion. Keep movement subtle, avoid using animation to communicate information by itself, and respect reduced-motion preferences.

.button { transition: transform 160ms ease; }
.button:hover { transform: translateY(-2px); }
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation-duration: .01ms; }
}

Expert · Maintainable CSS

Use modern tools and practice in a live playground

Custom properties centralize design decisions. Cascade layers make groups of styles predictable, and container queries make reusable components respond to their own size.

@layer reset, components, utilities;

:root { --accent: #1d6249; }
@layer components {
  .panel { border-color: var(--accent); }
}

.card-list { container-type: inline-size; }
@container (min-width: 32rem) {
  .card { display: grid; grid-template-columns: 1fr 2fr; }
}

Think like an expert: build a small, consistent set of rules; keep selectors easy to override; check keyboard focus and color contrast; and use browser devtools to inspect computed styles and layout.

Beginner · Readable interfaces

Make text clear and expressive

Typography is more than choosing a font. Set a comfortable line height, use a limited scale of sizes, and let headings wrap naturally on smaller screens.

body { font-family: system-ui, sans-serif; line-height: 1.6; }
h1 { font-size: clamp(2rem, 5vw, 3.5rem); line-height: 1.1; }
.intro { max-width: 60ch; }

Example: a responsive heading and readable paragraph

Good type helps people find their way.

Use a clear heading, a readable measure, and enough line spacing. The clamp() function lets a font size grow smoothly between a minimum and maximum.

10

Beginner · Color systems

Build a palette with custom properties

CSS custom properties store reusable values. Define them once, then use var() to keep buttons, links, and surfaces consistent. Check text contrast whenever you choose foreground and background colors.

:root {
  --brand: #1d6249;
  --surface: #e6f4e9;
  --ink: #18332a;
}
.button { background: var(--brand); color: white; }

Intermediate · Layering elements

Position elements with purpose

Normal document flow is the best starting point. Use position: relative to establish a local containing block, then position small overlays with offsets. Sticky elements stay in flow until they reach their threshold.

.card { position: relative; }
.badge { position: absolute; top: .75rem; right: .75rem; }
.toolbar { position: sticky; top: 0; }

12

Intermediate · Forms and states

Style accessible form controls

Connect every control to a visible label. Keep focus indicators obvious for keyboard users, and use native input types and validation before adding custom behavior.

input:focus-visible {
  outline: 3px solid #b8dfc2;
  border-color: #1d6249;
}
button:disabled { opacity: .55; cursor: not-allowed; }

Try it: click or tab into the fields

Intermediate · Selector patterns

Target states and relationships

Pseudo-classes such as :hover, :focus-visible, :first-child, and :nth-child() match an element's state or position. Combinators like > and + describe relationships between elements.

.menu > li:first-child { font-weight: 700; }
.menu li:nth-child(even) { background: #edf5ee; }
button:hover { filter: brightness(.9); }
